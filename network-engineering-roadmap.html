Phase 01 — Foundation
🖥️
Computer & OS Basics
// Start here — understand the machines
  • How computers work (CPU, RAM, Storage, NIC)
  • Operating systems: Windows, Linux, macOS
  • Linux CLI fundamentals (ls, cd, ping, ifconfig)
  • File systems and permissions
  • Virtualization basics (VirtualBox / VMware)
  • Packet Tracer / GNS3 lab setup
📡
Networking Fundamentals
// Core concepts every engineer must know
  • What is a network? LAN, WAN, MAN, PAN
  • OSI Model — all 7 layers explained
  • TCP/IP Model and comparison with OSI
  • IP addressing: IPv4, IPv6, subnetting (CIDR)
  • MAC addresses, ARP, NDP
  • Ethernet, cables, connectors, topologies
  • Switches, Routers, Hubs, Bridges, Access Points
🔢
Subnetting & Addressing
// Master binary and IP math
  • Binary, decimal, hexadecimal conversions
  • IPv4 classes (A, B, C, D, E)
  • Subnet masks and wildcard masks
  • CIDR notation and VLSM
  • Public vs private IP ranges (RFC 1918)
  • NAT, PAT, DHCP fundamentals
  • IPv6 addressing and types
🌐
Core Protocols
// How data moves across networks
  • DNS — how name resolution works
  • DHCP — dynamic address assignment
  • HTTP, HTTPS, FTP, SFTP, TFTP
  • SMTP, POP3, IMAP — email protocols
  • ICMP — ping, traceroute
  • TCP vs UDP — when to use each
  • Port numbers and well-known services
Phase 02 — Core Skills
🔀
Switching & VLANs
// Layer 2 switching mastery
  • How Ethernet switches work (MAC table)
  • VLANs — creating, configuring, inter-VLAN routing
  • Trunking (802.1Q), DTP, native VLAN
  • Spanning Tree Protocol (STP, RSTP, PVST+)
  • EtherChannel / LACP / PAgP
  • Port security and storm control
  • CDP/LLDP neighbor discovery
🛣️
Routing Protocols
// Layer 3 routing mastery
  • Static routing and default routes
  • RIP v1/v2 — distance vector basics
  • OSPF — link-state, areas, LSAs, SPF
  • EIGRP — hybrid, DUAL algorithm
  • BGP — eBGP, iBGP, path attributes
  • Route redistribution and filtering
  • Administrative distance and metrics
🔐
Network Security Basics
// Protect the infrastructure
  • Firewalls — stateful vs stateless, ACLs
  • VPN — IPsec, SSL/TLS, site-to-site, remote access
  • AAA — RADIUS, TACACS+ authentication
  • Port security, DHCP snooping, DAI
  • Common attacks: DoS, MITM, ARP spoofing
  • Network segmentation and DMZ
  • Cryptography fundamentals
📊
Network Monitoring & Tools
// Visibility and troubleshooting
  • Wireshark — packet capture and analysis
  • SNMP — monitoring, MIBs, OIDs, traps
  • Syslog — centralized logging
  • NetFlow / sFlow — traffic analysis
  • NMS tools: PRTG, Zabbix, Nagios
  • Ping, traceroute, nslookup, nmap
  • Network baselining and capacity planning
☁️
WAN Technologies
// Connecting remote sites
  • MPLS — labels, LDP, LSP, VPN
  • SD-WAN concepts and benefits
  • Metro Ethernet, leased lines
  • PPP, HDLC, Frame Relay (legacy)
  • DMVPN — hub-and-spoke, phase 1/2/3
  • QoS — DSCP, CoS, queuing, shaping
  • Broadband: DSL, cable, fiber
⚙️
Network Automation Intro
// Start automating your work
  • Python basics for network engineers
  • Netmiko — SSH automation
  • NAPALM — multi-vendor abstraction
  • Ansible for network automation
  • REST APIs and JSON/YAML
  • Git & version control for configs
  • Templating with Jinja2
Phase 03 — Advanced Engineering
🏗️
Network Design
  • Hierarchical design (Core/Dist/Access)
  • Spine-Leaf architecture
  • High availability & redundancy (HSRP, VRRP, GLBP)
  • Campus, DC, and WAN design
  • Capacity planning & traffic engineering
  • IPv6 migration strategies
🌩️
Cloud Networking
  • AWS VPC, subnets, route tables, IGW
  • Azure Virtual Networks & VPN Gateway
  • GCP networking fundamentals
  • Cloud interconnects (Direct Connect, ExpressRoute)
  • Transit Gateway, VPC peering
  • Cloud security groups and NACLs
🔬
Advanced Security
  • Zero Trust Architecture
  • Next-Gen Firewalls (Palo Alto, Fortinet)
  • IDS/IPS and SIEM integration
  • Micro-segmentation
  • PKI and certificate management
  • Penetration testing fundamentals
🤖
Advanced Automation
  • CI/CD pipelines for network configs
  • Terraform for network infrastructure
  • YANG models and NETCONF/RESTCONF
  • Nornir automation framework
  • Network testing with pytest
  • ChatOps with Slack/Teams bots
📦
Data Center Networking
  • VXLAN and EVPN overlay networks
  • ACI (Cisco Application Centric Infra)
  • NSX-T (VMware networking)
  • Storage networking (Fibre Channel, iSCSI)
  • Load balancing (F5, Citrix, Nginx)
  • Data center interconnect (DCI)
📶
Wireless & Mobility
  • 802.11 standards (a/b/g/n/ac/ax/be)
  • RF fundamentals, channels, SSID
  • WLC and lightweight AP architecture
  • 802.1X and EAP authentication
  • Roaming, QoS for voice/video
  • Wi-Fi 6/6E/7 features
Phase 04 — Expert / Architect
🧠
Network Architecture
// Design enterprise-scale networks
  • Enterprise architecture frameworks (TOGAF)
  • Multi-cloud and hybrid networking
  • SD-WAN design and deployment
  • SASE (Secure Access Service Edge)
  • 5G and edge computing integration
  • Intent-Based Networking (IBN)
  • Network Digital Twin concepts
⚡
Service Provider & Telco
// ISP-scale infrastructure
  • BGP advanced: communities, policies, peering
  • MPLS Traffic Engineering
  • Segment Routing (SR-MPLS, SRv6)
  • EVPN for carrier-grade services
  • Internet exchange points (IXP)
  • DDoS mitigation at scale
  • Network function virtualization (NFV)
